0.2.0 - 2026-01-06

New Functions - Shape Manipulation:
- ndarray_reshape(): In-place reshape with automatic dimension inference (use -1)
- ndarray_set_slice(): Set values along entire row/column/hyperplane from array
- ndarray_fill_slice(): Fill entire row/column/hyperplane with scalar value

New Functions - Fused Operations (BLAS-inspired):
- ndarray_axpby(): Linear combination A = alpha*A + beta*B using optimized BLAS
- ndarray_scale_shift(): Scale and shift A = alpha*A + beta in one operation
- ndarray_mul_scaled(): Element-wise multiply then scale A = A * B * scalar
- ndarray_map_mul(): Apply function then multiply A = func(A) * B * alpha
- ndarray_mul_add(): Fused multiply-add C = alpha*(A*B) + beta*C
- ndarray_gemv(): Matrix-vector multiply y = alpha*A*x + beta*y using BLAS dgemv

Improvements:
- All functions work for arrays of any dimensionality (2D, 3D, 4D, etc.)
- Comprehensive test coverage (81 tests, 698 assertions)
- Full Zig bindings for all new functions
- Documentation updates with examples in README.md and README-zig.md
- Performance optimizations using CBLAS routines where applicable
- Fused operations reduce memory bandwidth and improve cache efficiency

0.3.0 - 2026-01-06

New Functions - Conditional Operations:
- ndarray_clip_min(): Clip values below threshold (non-negativity, ReLU)
- ndarray_clip_max(): Clip values above threshold (saturation)
- ndarray_clip(): Clip to range [min, max] (normalized ranges)
- ndarray_abs(): Absolute value (distance, magnitude)
- ndarray_sign(): Sign function -1/0/+1 (direction indicators)

New Functions - Slice Access Helpers:
- ndarray_get_slice_ptr(): Direct pointer access to slices
- ndarray_copy_slice(): Safe slice-to-slice copying
- ndarray_get_slice_size(): Get number of elements in a slice

New Functions - Comparison Operations:
- ndarray_new_equal(): Element-wise equality (==)
- ndarray_new_less(): Element-wise less-than (<)
- ndarray_new_greater(): Element-wise greater-than (>)
- ndarray_new_equal_scalar(): Compare with scalar value
- ndarray_new_less_scalar(): Less-than scalar comparison
- ndarray_new_greater_scalar(): Greater-than scalar comparison

New Functions - Logical Operations:
- ndarray_logical_and(): Logical AND (combine conditions)
- ndarray_logical_or(): Logical OR (alternative conditions)
- ndarray_logical_not(): Logical NOT (invert condition)
- ndarray_where(): NumPy-style ternary operator (condition ? x : y)

Improvements:
- All functions work for N-dimensional arrays (2D, 3D, 4D+)
- SIMD-optimized conditional operations for performance
- Comprehensive test coverage (95 tests, 787 assertions)
- Enhanced API for data analysis, ML, and scientific computing
- Zero-copy slice access for advanced users
- Boolean masking and conditional replacement support
